# System requirements

## Supported platform

| Item | Requirement |
|------|-------------|
| OS | Windows 10 or Windows 11 |
| Architecture | **x64** (64-bit) |
| Installer | NSIS Free installer from GitHub Releases |

## Hardware

| Item | Recommendation |
|------|----------------|
| RAM | 8 GB minimum; 16 GB+ preferred when using larger GGUF models |
| Disk | Several GB free for the app; models can be several GB each |
| CPU | Modern x64 CPU (always required) |
| GPU | Optional NVIDIA GPU for faster local inference; CPU-only is supported |

Exact model performance depends on the GGUF you choose and your hardware.

## Network

- **Free chat path:** designed to work offline once the app and model are on disk
- **Optional network:** opening Upgrade / checkout links or validating a paid license (when Pro is live) may contact external services — see [Privacy](../legal/PRIVACY.en.md)
