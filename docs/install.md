# Install (Windows Free)

## Steps

1. Go to **[Latest release](https://github.com/andreibujaki/arya900/releases/latest)**
2. Download the Free Windows x64 installer (`.exe`)
3. Run the installer (per-user install is the default)
4. Start **Arya 900 Local Assistant Free** from the Start menu or desktop shortcut
5. Select a local GGUF model (or download one through the app catalog where available) and chat

## Windows SmartScreen / Application Control

Current Free builds are **not code-signed**.

- **SmartScreen:** “Windows protected your PC” → **More info** → **Run anyway**
- **Enterprise WDAC / AppLocker:** unsigned installers or apps may be blocked until IT allows them or a signed build is published

Signing is planned for a later release.

## After install

- Settings → **License** should show **Free**
- Legal documents open from Settings → License → Legal
- Free builds cannot activate Pro/Business keys — use the Free installer for Free; a full Pro-capable installer comes later

## Uninstall

Use Windows **Settings → Apps** (or the Start menu uninstall entry) for **Arya 900 Local Assistant Free**.
