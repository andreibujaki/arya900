# Arya 900 Local Assistant

**Offline Windows desktop chat** with local GGUF models — Free for personal light use.

Publisher: **EAROCO SERVICES SRL - ANDREI BUJAKI**

---

## Download (Free)

**→ [Latest Free release](https://github.com/andreibujaki/arya900/releases/latest)**

Artifact: `Arya 900 Local Assistant Free.Windows.*.x64.exe` (Windows 10/11, x64 installer)

1. Download the Free installer from the release page  
2. Run the installer and launch **Arya 900 Local Assistant Free**  
3. Load a local GGUF model and chat offline  

> **Note:** This build is **not code-signed** yet. Windows SmartScreen or enterprise Application Control may warn or block unsigned apps. Signing comes in a later release.
